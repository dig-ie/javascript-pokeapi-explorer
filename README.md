# 🔍 Pokédex com PokeAPI

Uma Pokédex interativa que consome dados da **PokeAPI**, exibindo informações de diversos Pokémon em tempo real.

![Preview da Pokédex](image.png)

---

## ⚙️ Funcionalidades

- Busca e listagem de Pokémon diretamente da [PokeAPI](https://pokeapi.co/)
- Exibição de nome, ID, tipo(s) e imagem do Pokémon
- Interface leve e responsiva

---

## 🛠️ Tecnologias Utilizadas

- **HTML**
- **CSS**
- **JavaScript**
- **PokeAPI**
