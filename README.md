# 🔍 Pokédex com PokeAPI

Uma Pokédex interativa que consome dados da **PokeAPI**, exibindo informações de diversos Pokémon em tempo real.

🔗 **Deploy:**  
https://diegodebarros.github.io/js-my-pokedex/

![Preview da Pokédex](image.png)

---

## ⚙️ Funcionalidades

- Busca e listagem de Pokémon diretamente da [PokeAPI](https://pokeapi.co/)
- Exibição de nome, ID, tipo(s) e imagem do Pokémon
- Interface leve e responsiva

---

## 🛠️ Tecnologias Utilizadas

- **HTML**
- **CSS**
- **JavaScript**
- **PokeAPI**

---

## 🚀 Como Executar Localmente

1. Clone o repositório:
```bash
git clone https://github.com/diegodebarros/js-my-pokedex.git
```

2. Acesse a pasta do projeto:
```bash
cd js-my-pokedex
```

3. Abra o arquivo `index.html` diretamente no navegador  
*(Você pode clicar duas vezes no arquivo ou usar uma extensão como "Live Server" no VSCode)*
